# Nexivo Design System

## Visual Direction

Nexivo uses a premium travel marketplace and enterprise SaaS visual system.

Core principles:

- Modern
- Elegant
- Unique
- GCC-first
- Europe-ready
- Mobile-first
- Luxury travel inspired
- Business software credible

## Typography

- Body: Inter

Arabic:
- Headings: IBM Plex Sans Arabic
- Body: Tajawal
